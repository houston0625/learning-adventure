數學四上・第三單元 角度

3-1 量角器

    回單元

    重點整理：量角器

    認識量角器（p.32～33）

    • 量角的大小，單位是「度」，記成「°」。
    • 外圈從左到右、內圈從右到左，都是 0～180。
    • 1 小格是 1°，1 大格（10 小格）是 10°。

    量角的步驟（p.36）

    • ① 中心點對準角的頂點。
    • ② 0 度線對齊角的一邊。
    • ③ 從 0 開始，數到角的另一邊。
    • 邊太短就把兩邊延長，角的大小不會變。

    讀哪一圈？（p.34～35）

    • 對齊外圈的 0 就讀外圈，對齊內圈的 0 就讀內圈。
    • 兩邊都不在 0 線上：一大格 10° 數過去，或用大的刻度減小的刻度。

    角的分類（p.38～39）

    • 銳角：比 0° 大、比 90° 小。
    • 直角：剛好 90°。
    • 鈍角：比 90° 大、比 180° 小。
    • 平角：兩邊成一直線，180°。

    畫角（p.40）

    • 先畫一條直線當一邊，一端當頂點。
    • 中心點對準頂點，直線對齊 0 度線。
    • 順著同一圈數到度數，做記號，再連成直線。
    • 誤差在 2° 以內都算對。
