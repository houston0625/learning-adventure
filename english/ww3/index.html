給爸爸媽媽

  1. 英文的單字和句子都會用英文語音念出來，請把聲音打開。iPad 可以到「設定 → 輔助使用 → 朗讀內容 → 聲音 → 英文」下載更自然的聲音（例如 Samantha）。
  2. 「換我說」是跟讀麥克風：孩子念完，皮皮會給星星。第一次使用時 Safari 會問能不能用麥克風，請按「允許」。辨識是用 Apple（或 Google）的語音服務轉成文字，網頁不錄音、不保存。孩子的發音辨識不一定準，星星少也請多鼓勵。
  3. 如果 iPad 沒有開「聽寫」功能，麥克風可能不能用（設定 → 一般 → 鍵盤 → 啟用聽寫）；不能用時，孩子大聲念一遍，按「我念完了」就可以。
  4. 每一關都可以直接點上方的關卡跳過去；最後的小測驗可以一直重新挑戰。
